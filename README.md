# 🍃 Calorie Crafters

AI-Based Food Calorie Estimator and Nutrition Tracker.

## Features

- AI food image recognition
- Food search
- Calorie estimation
- Protein, carbs and fat estimation
- Portion/quantity calculation
- Daily calorie tracking
- SQLite food history
- Interactive nutrition dashboard
- Responsive web interface

## Technologies

- Python
- Flask
- Hugging Face Transformers
- PyTorch
- Pillow
- Pandas
- NumPy
- SQLite
- HTML
- CSS
- JavaScript
- Plotly

## AI Model

The project uses the Hugging Face
`nateraw/food` image classification model.
